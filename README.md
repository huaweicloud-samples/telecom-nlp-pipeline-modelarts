[![Status](https://img.shields.io/badge/Status-Incubating-blue)]()

This project provides a complete NLP training pipeline built on Huawei Cloud ModelArts and OBS, offering three core capabilities: custom entity recognition (BERT-NER), Word2Vec embeddings (gensim), and negative sentiment classification (fastText). Targeting text analysis scenarios such as telecom tweet corpora, it utilizes three Jupyter Notebooks for training with data stored uniformly in OBS. The resulting training artifacts can be deployed as ModelArts online endpoints or wrapped as FunctionGraph functions exposed through APIG as REST APIs. It is designed for teams that need to train custom entity recognition, word embedding, or text classification models from their own corpora.
